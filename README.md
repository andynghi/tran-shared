# tran-shared

Tài liệu chia sẻ — xem thẳng trên GitHub.

```
md/     tài liệu Markdown — GitHub render sẵn, bấm vào là đọc được
html/   trang HTML — xem mục dưới
```

## File `.html` — GitHub KHÔNG render

Bấm vào một file `.html` trong repo, GitHub hiện **mã nguồn**, không hiện trang. Hai cách xem thật:

1. **GitHub Pages** — bật ở **Settings → Pages → Source: `Deploy from a branch` → `main` / `/ (root)` → Save**.
   Xong thì mỗi file trong `html/` xem được ở `https://andynghi.github.io/tran-shared/html/<tên-file>.html`
2. Không bật Pages thì dán đường dẫn raw vào `https://htmlpreview.github.io/?<raw-url>` —
   được ngay, không cần cấu hình.

`.md` thì không cần gì cả — GitHub tự render.

## ⚠️ Repo này PUBLIC

Ai cũng đọc được, và **git giữ lại lịch sử kể cả sau khi xoá file**. Không đưa vào đây:
họ tên đầy đủ, tên trường, ảnh có mặt người, hostname hay đường dẫn máy riêng, token, hay bất cứ
thứ gì riêng tư. Bài vở và hình vẽ thì không sao.
